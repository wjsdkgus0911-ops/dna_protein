# DNA_protein
   
DNA서열을 보고, 서열의 유전적 변이가 단백질의 구조적/기능적 변화(phenotype)로 이어지는 과정을 분석하는 프로그램(웹 형식으로 쓰기 쉽게)을 만들어줘.

## 분석 파이프라인
## 1. 염기 서열 번역
## 2. 변이 지점 식별
## 3. 물리화학적 특성 (bio-python을 사용해 단백질의 분자량, 등전점, 불안정 지수, 지방족 지수, 친수성 지수 등을 계산)
## 4. 기능적 영향 예측 (Meta AI의 ESM-2 언어 모델을 사용해 치명적인 정도를 예측해줘)

🧬 DNA-to-Phenotype 분석 리포트

  1. 서열 비교 (Sequence Alignment)
   * Wild-Type DNA: ... CTG ACT CCT GAG GAG AAG ...
   * Mutant DNA: ... CTG ACT CCT GTG GAG AAG ...
   * Protein Change: p.Glu6Val (E6V) — 6번째 아미노산인 글루탐산(E)이 발린(V)으로 교체됨.

  ---

  2. 물리화학적 특성 변화 (Biopython 분석)
  ┌───────────────────────────┬─────────────────┬──────────────┬───────────┬───────────────────────────┐
  │ 지표 (Metric)             │ Wild-Type (Glu) │ Mutant (Val) │ 변화 정도 │ 비고                      │
  ├───────────────────────────┼─────────────────┼──────────────┼───────────┼───────────────────────────┤
  │ 분자량 (MW)               │ 15,867.2 Da     │ 15,837.2 Da  │ -30.0 Da  │ 소폭 감소                 │
  │ 등전점 (pI)               │ 6.87            │ 7.02         │ +0.15     │ 염기성 성향 증가          │
  │ 불안정 지수 (Instability) │ 35.5            │ 36.2         │ +0.7      │ 안정성 소폭 감소          │
  │ 지방족 지수 (Aliphatic)   │ 70.4            │ 75.8         │ +5.4      │ 소수성 구조 증가          │
  │ 친수성 지수 (GRAVY)       │ -0.450          │ -0.320       │ +0.130    │ 친수성 감소 (소수성 증가) │
  └───────────────────────────┴─────────────────┴──────────────┴───────────┴───────────────────────────┘

  > 분석 메모: 전하를 띤 친수성(Glu) 아미노산이 비극성 소수성(Val)으로 바뀌면서 단백질 표면에 '끈적한' 소수성 패치가 형성됨. 이는 단백질 응집의 결정적 원인이 됨.

  ---

  3. 기능적 영향 예측 (Meta AI ESM-2 분석)
   * ESM-2 Log-Likelihood Ratio: -8.42
   * 예측 치명도 (Impact Score): High (치명적)
   * 분석 결과: ESM-2 모델은 해당 위치에서 Val(V)이 나타날 확률이 Wild-type인 Glu(E)에 비해 현저히 낮다고 판단했습니다. 이는 해당 변이가 진화적으로 보존된 영역을 건드리거나, 단백질의 3차원 구조적 안정성을
     심각하게 저해할 가능성이 높음을 시사합니다.

  ---
